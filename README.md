# Studio_Meirelles

Landing page do Studio Meirelles (social media e design para profissionais da saúde).

## Como ver

Abra o `index.html` no navegador. É um arquivo único, sem build e sem dependências além das fontes do Google Fonts.

## Pendências antes de publicar

Tudo que está entre colchetes na página precisa ser resolvido com a Dani:

- **Imagens**: 2 fotos da Dani e 6 imagens de portfólio (hoje são caixas tracejadas).
- **Depoimentos**: confirmar nomes e autorização de uso.
- **Serviços**: entregas de cada serviço.
- **Investimento**: mostrar valores, faixas ou "sob consulta".
- **Reconhecimento SMCEO 100K**: confirmar a descrição.
